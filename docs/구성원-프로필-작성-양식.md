# LEAD AI Lab 구성원 프로필 작성 양식

양식 기준일: 2026-11-15 · 홈페이지 구성원·졸업생 프로필 칸과 같은 순서입니다.

> 담당자용 사용법: 새 구성원(또는 졸업 예정자)에게 이 양식을 보내 내용을 받은 뒤, 관리 화면에 옮겨 적습니다([홈페이지 관리 가이드 3-2](홈페이지-관리-가이드.md#3-2-구성원-추가수정)).
> 보낼 때는 아래 내용을 Word·한글·Google 문서 등에 붙여 넣고, 제출 기한·제출할 곳을 채운 뒤 맨 아래 **담당자 메모** 절은 빼고 보냅니다.
> 받은 양식 파일(서명한 공개 동의가 담긴 것)은 이 저장소에 올리지 말고 연구실 내부에만 보관합니다.

## 작성 안내

이 양식의 내용은 연구실 홈페이지([smu-edtech-lab.github.io/lead-ai-lab](https://smu-edtech-lab.github.io/lead-ai-lab/))의 People 목록과 개인 프로필 페이지에 실립니다. 각 칸을 채워 사진과 함께 제출해 주세요.

- 제출 기한: ____년 __월 __일
- 제출할 곳: ____________ (담당자 이름·이메일)

**공개 범위를 먼저 확인해 주세요.** 홈페이지 파일은 공개 저장소(GitHub)에 보관됩니다. 그래서 적어 낸 내용은 사이트에 보이지 않는 칸까지 누구나 볼 수 있고, 나중에 지워도 변경 기록에는 남습니다. 공개해도 되는 내용만 적고, 8번에서 항목별로 공개 여부를 표시해 주세요.

작성 요령:

- 날짜는 점으로 적습니다: `2025`, `2025.03`. 진행 중이면 `2025.03 – 현재`.
- 논문·발표·수상은 원문 표기 그대로 적습니다 (제목, 저자 순서, 학술지·학회 이름).
- 표의 줄이 모자라면 줄을 더 넣고, 해당 없는 칸은 비워 둡니다.
- 학번, 생년월일, 집 주소, 개인 휴대전화 번호는 적지 않습니다.

## 담당자 메모: 관리 화면에 옮겨 적기

학생에게 보낼 때는 이 절을 지우고 보냅니다. 받은 양식은 관리 화면 › **구성원** 에서 아래처럼 옮겨 적습니다([홈페이지 관리 가이드 3-2, 3-5](홈페이지-관리-가이드.md#3-자주-하는-일)).

| 양식 | 관리 화면 칸 |
| --- | --- |
| 1. 이름, 영문 이름 | 기본 정보 › 이름, 영문 이름 (주소는 영문 이름으로 자동 제안, 게시 후 변경 불가) |
| 1. 과정, 화면에 보일 과정 이름 | 과정, 화면에 보일 과정 이름 (‘기타’ = 구성원) |
| 1. 입학·합류, 공개 이메일 | 입학·합류, 공개 이메일 |
| 2. 사진 | 프로필 사진 (세로 4:5로 자동 자름) |
| 3. 연구 관심사, 연구 분야, 자기소개 | 연구 관심사(쉼표), 연구 분야(체크), 소개 |
| 4. 연구실적 | 상세 프로필 › 연구실적 (연도·기간 / 내용 / 보조 정보) |
| 5. 참여 연구 프로젝트 | 상세 프로필 › 참여 연구 프로젝트 (연구실 과제면 ‘연구실 과제’에서 고름 / 기간 / 역할 / 지원 기관은 보조 정보) |
| 6. 수상경력 | 상세 프로필 › 수상경력 (연도 / 내용 / 보조 정보) |
| 7. 이력 | 상세 프로필 › 이력 (학력·경력) |
| 8. 공개 동의 ‘아니요’ | 그 항목은 **입력하지 않음**. ‘사이트에 표시’를 끄는 것으로는 공개 저장소에서 숨겨지지 않음 |
| 9. 졸업 항목 | 구성원 편집 화면 › **졸업생으로 옮기기** 화면의 학위, 졸업 연도, 학위논문, 현재 소속 |
